# 🚀 Azure 3-Tier Architecture

## 📌 Project Overview

This project demonstrates the deployment of a **3-Tier Architecture** on **Microsoft Azure** using Virtual Machines, Networking, and Security services.

### 🏗️ Architecture

🌐 User
   │
   ▼
🖥️ Nginx (Web Tier)
   │
   ▼
⚙️ Apache Tomcat (Application Tier)
   │
   ▼
🗄️ MySQL (Database Tier)
```

## ☁️ Azure Services Used

✅ Azure Virtual Machines
✅ Azure Virtual Network (VNet)
✅ Network Security Groups (NSG)
✅ Azure Load Balancer
✅ Public IP Address

## 🛠️ Technologies

* Linux
* Nginx
* Apache Tomcat
* MySQL
* Microsoft Azure

## 📋 Deployment Steps

1️⃣ Created Resource Group
2️⃣ Created VNet and Subnets
3️⃣ Deployed Virtual Machines
4️⃣ Installed Nginx, Tomcat, and MySQL
5️⃣ Configured NSG Rules
6️⃣ Tested End-to-End Connectivity
